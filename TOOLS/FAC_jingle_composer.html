🎵 F.A.C. Jingle Composer Guide

1. Setup & Configuration: Enter a File Name for your project to name the generated C++ function. Set your base tempo with the BPM slider and use the Multiplier (1x - 5x) to increase playback speed and code timing resolution.

2. Composing on the Grid: Click a cell to set focus. Click a Piano Key to assign a note; the cursor will automatically advance. Click and drag to select multiple columns.

3. Smart Editing: Use Backspace (or the red ⌫ button) to delete a note and move the selection back by one step, allowing for rapid "type-and-correct" editing.

4. Note Management:

  • Link Notes (🔗): Select adjacent cells with the same note and click "Link" to create a single sustained sound.
  • Split Notes (✂️): Removes ties from selected notes.
  • Ins/Del Column: Insert space or shift the entire track.

5. Exporting: The C++ code updates in real-time. Use Copy Function for your firmware or Export .MID to save the project file for later use.

Keyboard Shortcuts: [Space] Play/Pause | [Backspace] Delete & Back | [Click+Drag] Select
